# DST · demo prezentacija

Prezentacija za demo programa DST (studeni 2026.), na hrvatskom.

Otvorite `index.html` (ili GitHub Pages stranicu). Navigacija: strelice ← →, razmaknica, `F` za cijeli zaslon. Klik na sliku je povećava; 3D dijelovi se okreću mišem.

Slike i 3D modeli su DST-ovi ogledni primjeri; nazivi klijenata i osoba su izmišljeni ili uklonjeni.
